# İzmir Ticaret Odası — Anasayfa Tasarımları

Üç bağımsız (standalone) anasayfa tasarımı. Her dosya tek başına tarayıcıda açılır.

- 1a-klasik-kurumsal.html — Lacivert otorite, kurumsal derinlik
- 1b-modern-ege.html — Editoryal poster tipografisi, ferah kompozisyon
- 1c-acik-ferah.html — Açık/beyaz zemin, işlem odaklı, interaktif (arama sekmeleri, haber filtresi, SSS akordiyonu)

## Kurulum
Dosyaları olduğu gibi sunucuya / GitHub Pages'e koyun. fonts/ klasörü Neuzeit Grotesk yazı tipini içerir.
İkonlar Lucide CDN üzerinden yüklenir (internet gerekir); istenirse yerelleştirilebilir.

## Notlar
- Logo api.izto.org.tr üzerinden çekilmektedir.
- Görseller örnek amaçlı picsum.photos üzerindendir; gerçek görsellerle değiştirilmelidir.
- Piyasa kurları ve tarihler örnektir.
- Temel responsive kırılımlar eklenmiştir (<=1040px ve <=680px).
